## Plan (Gate 1)

### Scope
The client wants the coach profile print preview page to look exactly like the member one — common UI. Port the member print-preview design (from `resources/js/pages/members/print-preview.tsx`, 2802 lines) to `resources/js/pages/coaches/print-preview.tsx` (819 lines): letterhead with border rule, print-only watermark + double border frame, cloned print window with `print-color-adjust: exact`, pill-style section toggles replacing the left sidebar, member-style Section/DetailsTable/DetailStack helpers with `print:*` overrides. Keep coach sections and data (no new backend props needed — `CoachProfileData::print` already provides coach/coachTeams/statusHistory/coachAchievements). Coach photo moves from letterhead to a photo box in the profile section (member pattern). Out of scope: member-only data the coach doesn't have (audit-log timeline, story/compact timeline mode).

## Summary (Gate 3) — fill after implementation

### What changed
- Rebuilt `resources/js/pages/coaches/print-preview.tsx` on the member print-preview design:
  - Sheet container is now the member's `printTargetRef` wrapper (`relative mx-auto max-w-5xl ... rounded-2xl border ... bg-white`, `id="quick-view-print-target"` so the global `app.css` print rules apply), with the print-only double border frame and 4.5%-opacity centered logo watermark copied verbatim.
  - Screen-only toolbar row (`print:hidden`) replaces the old two-column layout + left sidebar: breadcrumb text (`Coaches / {name}`), page title, `LocaleSwitcher`, Back (`CoachController.show.url(coach)` via Wayfinder) and Print buttons.
  - Letterhead matches member exactly: `size-20` (`print:size-16`) logo left of the centered block, bold uppercase "UP Police Sports Control Board", "Coach profile record" subtitle, "Official print preview" meta, `border-b-2 border-neutral-900` rule, `w-20` print spacer. Coach photo removed from the letterhead.
  - Print options are now member-style inline pill checkboxes in a dashed `bg-neutral-50` bar (`print:hidden`); all 8 existing coach section toggles and the default-enabled set are unchanged.
  - Profile section follows the member identity pattern: name block + `DetailsTable` on the left, photo box (`size-28`, `print:size-24`) on the right with the member's "No photo" text fallback when `photo_path` is null.
  - `DetailTable`/`DataTable` helpers restyled to member idioms (`DetailsTable` with `overflow-hidden rounded-md border` wrapper, `bg-muted/30` label column, `print:text-[10px]`/`print:py-1`/`print:text-[9px]` overrides; `DataTable` with `bg-muted/40` uppercase thead, `border-t` row separators, `break-inside-avoid` Section with `print:text-[10px]` header). All data rendering (medal chips, certifications, promotions, team assignments, status history) preserved.
  - Print mechanism ported from member: `handlePrint` clones the sheet (`outerHTML`) into a new window with copied `<head>` assets plus inline CSS (`@page { margin: 0.6cm }`, white body, `img { print-color-adjust: exact }`) and prints that window; the `document.title = filename` behavior is kept; a `useEffect` `@media print` override (member `:1249-1267`) supports direct browser print of just the sheet.
- `resources/lang/hi.json`: added 3 new keys for new user-facing strings — `"No photo"`, `"Official print preview"`, `"Print preview"` (Hindi values taken from the member page's inline labels).

### Decisions
- Reused the member's `id="quick-view-print-target"` so the existing global print stylesheet in `resources/css/app.css` applies to the coach page too.
- Dropped the page's own `bg-muted/30` wrapper — the gray screen background comes from the app shell (inset sidebar variant), same as the member page.
- Used `t('UP Police Sports Control Board')` (already translated in hi.json) instead of the old hardcoded literal, to match member's localized letterhead.
- Did not port member-only features the coach has no data for (story/compact timeline, audit log).
