## Plan (Gate 1)

### Scope
The team prabhari (incharge) module currently shows several English labels when the application language is set to Hindi. This task audits all translation keys used in the incharge pages/components and adds the missing Hindi and English keys. It also localizes raw enum codes (achievement level, medal type, gender class) that are displayed without translation.

### Files to touch
- `resources/js/pages/incharges/index.tsx` — breadcrumb translation.
- `resources/js/pages/incharges/show.tsx` — localized enum display for level/medal/gender, localized select labels.
- `resources/js/pages/incharges/print.tsx` — localized print heading and enum normalization.
- `resources/js/components/teams/team-incharge-panel.tsx` — ensure labels are keyed (already mostly wrapped; add missing English keys only).
- `resources/lang/en.json` — add missing English keys used by incharge module.
- `resources/lang/hi.json` — add missing Hindi keys used by incharge module.

### Schema / endpoints / pages
- No migrations or backend changes.
- Pages affected:
  - `/incharges`
  - `/incharges/{incharge}`
  - `/incharges/{incharge}/preview`
  - `/teams/{team}` (team prabhari panel)

### Risk + mitigation
- **Risk:** Adding duplicate keys or changing key casing breaks existing translations.
  **Mitigation:** Only add keys that do not already exist; keep existing keys untouched.
- **Risk:** Localizing enums changes display in English if keys are missing.
  **Mitigation:** Add uppercase enum keys to `en.json` as well.

### Test plan
- Manual UI check: switch app language to Hindi and open incharge listing/show/preview and team prabhari panel; verify labels appear in Hindi.
- Run `npm run build` and `npx eslint` on changed files.
- Run `php artisan test --compact` (no PHP changes, but verify no regressions).
