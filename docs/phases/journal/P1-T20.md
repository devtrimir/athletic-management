## Plan (Gate 1)

### Scope
Create `database/data/sports.csv` (sports found in source workbooks), an `OrganizationSeeder` (creates the default UPP org — prerequisite for sports FK), and a `SportSeeder` that reads the CSV and upserts idempotently. Register both in `DatabaseSeeder`.

### Boost MCP research
- `database-schema` → `organizations`: `id, name, code (unique)`; `sports`: `id, organization_id FK, name_hi, name_en, category ENUM, slug, unique(organization_id, slug)`.
- Sports extracted from `analysis/manifest/value_samples.json` (Krutidev decoded from source workbooks 2019-2025 + 2026).

### Files to touch
| File | Change |

### Design
- `OrganizationSeeder`: `Organization::firstOrCreate(['code' => 'UPP'], ['name' => 'UP Police Sports Unit'])`
- `SportSeeder`: `SplFileObject` CSV → rows with `organization_id`, `slug = Str::slug($nameEn)` → `Sport::upsert(uniqueBy: ['organization_id', 'slug'], update: [...])`

### Test plan
- Count matches CSV rows after first seed
- Idempotent (re-run stays same count)
- All rows have valid `category` (one of INDIVIDUAL/TEAM/COMBAT/WATER)
- UPP org is created by `OrganizationSeeder`
