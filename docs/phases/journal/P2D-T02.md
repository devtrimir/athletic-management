## Plan (Gate 1)

### Scope
Support home districts from outside the state master list without polluting the core `districts` master table.
Add an `other_home_district` field to members, support dual-template sample downloads (Standard UP Districts vs. Extended with Out-of-State Home District) with intelligent import engine auto-detection, wire the `__other__` selection in Create/Edit forms, and unify display across Show profile, Quick View, Excel Export, Listing Print, Print Preview, and Audit Logs.

### Schema / endpoints / pages
- **Migration:** Add `other_home_district` (VARCHAR 255, nullable, after `home_district_id`) to `members` table.
- **Endpoint update:** `GET /members/import/template?type=standard|extended` — downloads chosen sample template.
- **Component update:** `MemberImportDialog` offers Standard and Extended template downloads.

### Risk + mitigation
- **Risk:** Existing uploaded Excel files without the new column might fail during import.
  **Mitigation:** `MembersImport` dynamically inspects column headers: if 20 columns (Standard), it maps using the standard schema; if the 21st column is present (Extended), it reads `other_home_district`. Moreover, even in Standard mode, any district string not matching the UP master list gracefully falls back to `other_home_district` instead of throwing an error.
- **Risk:** Blank or conflicting data when both `home_district_id` and `other_home_district` are sent.
  **Mitigation:** Form logic clears `other_home_district` when a master district is picked, and clears `home_district_id` when `__other__` is selected.

### Decisions
- **Master Data Integrity:** The `districts` master table represents UP police jurisdiction districts and remains untainted. Out-of-state home districts reside in `members.other_home_district`.
- **Dual Template with Contextual Import Auto-Detection:** The import dialog provides clear choices (Standard for UP districts with dropdown validation vs. Extended with out-of-state column). The backend import engine inspects the headers to determine the schema automatically, without requiring user metadata during upload.
- **Mutual Exclusivity:** Form Requests enforce `prohibits`, controllers enforce nullification of opposing fields, and Excel import updates properly clear obsolete fields when toggling between state and out-of-state districts.
