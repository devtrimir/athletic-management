## Plan (Gate 1)

### Scope
`EventParticipantController` — transactional bulk write of participations + optional achievements.
Route `POST /tournaments/{tournament}/events/{event}/participants` wraps each participant row in `DB::transaction()`, upserts participation, then upserts or clears achievement.

### Boost MCP research (mandatory)
- `search-docs` queries=["database transactions", "upsert bulk insert", "updateOrCreate multiple"] → use `DB::transaction()` + `Model::updateOrCreate()` per row (preferred over raw `upsert` because we need the participation ID to link the achievement)
- `database-schema` participations: unique `(event_id, member_id)`, has `session_id` column (populated from `$tournament->session_id`)
- `database-schema` achievements: `participation_id FK`, `medal_type ENUM('GOLD','SILVER','BRONZE','MERIT')`, `position`, `remarks`
