### Decisions
- **ENUM for `code`:** The closed set of tier values is enforced at DB level; out-of-range values are rejected by MySQL before Laravel validation even runs.
- **`weight` smallint:** Enables deterministic sort order (INTERNATIONAL=100, NATIONAL=80, … OTHER=10) without relying on string ordering.
