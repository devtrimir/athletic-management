## Summary

**Issue:** `TournamentProfileData` used MySQL-only `JSON_LENGTH(lineup_member_ids)` in 3 queries, crashing tournament pages on PostgreSQL (`SQLSTATE[42883] function json_length(json) does not exist`) after tournament creation redirects to listing. SQLite test DB also lacked the function (6 latent test failures masked as 500s).

**Fix:** driver-aware `lineupCountTotalExpression()` — pgsql → `JSONB_ARRAY_LENGTH(lineup_member_ids::jsonb)`, sqlite → `JSON_ARRAY_LENGTH`, mysql → `JSON_LENGTH`. Replaced in `appendAggregateCounts()` and `eventsPayload()` (3 sites).

**Side fix:** stale test assertion `eventFilters.gender_class` → `eventFilters.gender` (backend and frontend agree on `gender`; test was never exercised past the 500).
