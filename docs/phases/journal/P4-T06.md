### Schema / endpoints / pages
- `POST /teams/{team}/members` — bulk insert into `team_members`; 422 if any `member_id` already in team
- `DELETE /teams/{team}/members/{member}` — delete `team_members` row where `team_id + member_id`
- `POST /teams/{team}/coaches` — insert into `coach_assignments`; 422 if `(team_id, coach_id, role)` exists
- `DELETE /teams/{team}/coaches/{coach}` — delete `coach_assignments` row
