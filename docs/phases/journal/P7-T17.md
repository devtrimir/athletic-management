## Plan (Gate 1)

### Scope
`reports/show.tsx` uses `JSON.stringify(row[col])` for any object-valued cell, causing raw JSON strings to appear in the generic report table. Affected reports: `team-roster` (columns `team` = object, `members` = array of member-role objects) and `medal-tally` (column `tier` = object). Fix: add a `renderCellValue(val: unknown): string` helper that extracts a display-friendly label from objects/arrays, placed above the component function.

### renderCellValue logic
```
renderCellValue(val: unknown): string
  null/undefined          → ''
  Array                   → map each item through renderCellValue, filter empty, join ', '
  object with .member key → extract .member.full_name_hi ?? .member.name_hi ?? .member.name
  object                  → obj.name_hi ?? obj.name ?? obj.label ?? obj.code → first truthy
  fallback (object)       → JSON.stringify (preserves original behaviour for unknown shapes)
  primitive               → String(val)
```

This covers both affected reports:
- `team-roster` `team` col: `{ name_hi: "..." }` → `name_hi` ✓
- `team-roster` `members` col: array of `{ member: { full_name_hi: "..." }, role, ... }` → comma-separated names ✓
- `medal-tally` `tier` col: `{ code, label, weight }` → `label` ✓
