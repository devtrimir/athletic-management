### Seeder logic
1. Read `SEED_ADMIN_EMAIL`, `SEED_ADMIN_PASSWORD`, `SEED_ADMIN_NAME` from env.
2. Guard: non-local + empty vars → `\RuntimeException`. Local fallback: `admin@upp.local` / `password`.
3. `Organization::firstOrCreate(['code' => 'UPP'])`.
4. `Role::firstOrCreate([...code => 'admin'], ['is_system' => true])`.
5. `User::updateOrCreate(['email' => $email], [...])`.
6. `$user->assignRole($adminRole, $org)` — idempotent via `firstOrCreate`.

### Tests
- User created with correct email + org + email_verified_at
- Admin role has is_system = true
- User has admin role in UPP org
- Idempotent (re-run produces no duplicates)
- Non-local without env vars throws RuntimeException

## Boost MCP research
