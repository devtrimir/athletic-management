- `docs/TASKS.md` — P2-T10 ticked.

### Decisions
- **`assertSessionHasErrors()` over `assertUnprocessable()`:** Inertia non-XHR validation failures redirect back (302) with errors in session — not a 422. Matches pattern used in all other feature tests in this project.
- **`assertSoftDeleted()` over `$member->fresh()` null check:** `fresh()` returned the soft-deleted model unexpectedly due to test state interaction; `assertSoftDeleted()` is the canonical Laravel assertion for this.
- **Stub TSX pages created now:** without them the Vite manifest throws `ViteException` on Inertia render tests. Stubs are the minimal valid React components; real pages are T15–T19.
