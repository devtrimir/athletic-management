## Plan (Gate 1)

### Scope
Convert the synchronous member Excel import (`MemberImportController::store`) into a queued background job and push the result to the members index page over Laravel Reverb (WebSocket) instead of polling: upload → `PROCESSING` Import record → `ProcessMemberImportJob` on the default queue → `MemberImportFinished` broadcast on an org-scoped private channel → Echo subscriber live-reloads the members table + shows a sonner toast.

### Boost MCP research (mandatory)

- `search-docs` queries=`["reverb install broadcasting", "laravel echo react useReverb", "broadcasting events private channel", "install:broadcasting artisan"]` → `php artisan install:broadcasting --reverb` scaffolds composer (laravel/reverb) + npm (laravel-echo, pusher-js) + `config/broadcasting.php` + `routes/channels.php` + `.env` vars; `ShouldBroadcast` requires `broadcastOn`; anonymous `Broadcast::on()->as()->with()` exists but a dedicated event class is cleaner for a typed payload.
- `search-docs` (planning, v3 broadcasting docs) → Echo client config for the `reverb` broadcaster uses `VITE_REVERB_*` env vars; `laravel-echo` v1.16+ required.
- Skills consulted: `laravel-best-practices`, `pest-testing`, `inertia-react-development` (auto-activate during implementation).

### Risk + mitigation

- **Risk:** making the import async breaks the 20 existing `MemberImportTest` scenarios that assert members exist immediately after POST.
  **Mitigation:** run the queue synchronously in the test suite (`QUEUE_CONNECTION=sync` in `phpunit.xml`); dispatch tests use `Bus::fake()` in a separate file. Existing tests stay green untouched.
- **Risk:** uploaded temp file never cleaned up if the job crashes.
  **Mitigation:** `Storage::delete()` in a `finally` in the job; job marks the Import record `FAILED` + broadcasts failure payload before re-throwing so the UI never hangs.
- **Risk:** broadcasting to the wrong org leaks member data.
  **Mitigation:** private channel `organization.{id}` authorized via channel callback comparing `user.organization_id`; org-isolation test included.

### Test plan

- Pest Feature `MemberImportQueueTest`: upload dispatches `ProcessMemberImportJob` (Bus::fake), Import record persisted as `PROCESSING`, file stored on disk; viewer without `imports.run` → 403.
- Pest Feature `ProcessMemberImportJobTest`: job processes fixture XLSX → members created/updated, record `COMPLETED` with counts, temp file deleted; template-mismatch workbook → `FAILED`; `Broadcast::fake()` asserts `MemberImportFinished` on `private-organization.{orgId}` with payload.
- Pest Feature `BroadcastChannelTest`: org A user denied on org B channel, allowed on own.
- Existing `MemberImportTest` (sync queue) unchanged — regression coverage for the moved import logic.
