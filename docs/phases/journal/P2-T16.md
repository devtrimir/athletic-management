## Plan (Gate 1)

### Scope

### Boost MCP research (mandatory)
- `search-docs` `@inertiajs/react` `"useHttp hook"` → `useHttp` has `get(url, opts)`, `cancel()`, `processing`; `cancel()` calls `AbortController.abort()` internally.
- `useHttp` TypeScript type confirmed: `useHttp<TForm, TResponse>(data)` → returns `{ get, cancel, processing }`.
- `@headlessui/react` v2.2.10 exports `Combobox`, `ComboboxInput`, `ComboboxOptions`, `ComboboxOption`, `ComboboxButton` — full keyboard navigation + ARIA.
- Wayfinder: `MemberSearchController.url({ query: { q } })` builds `/api/v1/search/members?q=…`.
- `MemberSearchResource` (ADR-0004 frozen): `id, member_code, pno, full_name_hi, full_name_en, player_category, player_level, current_status` — **no `current_unit_name`**.

**Doc drift found:** Phase spec says "Shows: name (Hindi), PNO, unit" but frozen search contract has no unit field. Will show `full_name_hi` + PNO in dropdown rows. Adding `unit` requires a phase-8 migration plan (ADR-0004) — deferred.

**Spec flag:** TASKS.md canonically says `useHttp` (not TanStack Query). Neither TanStack Query nor `cmdk` is installed. Using `useHttp` + `@headlessui/react` Combobox (both already installed).
