### Risk + mitigation
- **Risk:** Bumping `composer.json` `php: ^8.4` may cause `composer install` to fail if any package still has a `>=8.3 <8.4` upper bound.
  **Mitigation:** `composer.lock` already resolves all packages against PHP 8.4 (confirmed by CI failure on 8.3). The bump only formalises what's already true; `composer validate` will confirm.
- **Risk:** Changing `.env.example` to mysql breaks the CI tests that copy `.env.example` (tests use SQLite).
  **Mitigation:** CI (`tests.yml`) runs on PHP 8.4. The test suite currently uses the in-memory SQLite driver via `phpunit.xml` override (`DB_CONNECTION=sqlite`). `.env.example` is only a developer reference; CI's `phpunit.xml` env overrides take precedence.
