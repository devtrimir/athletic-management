## Summary (Gate 3)

### What changed
- `database/migrations/2026_05_21_122703_create_audit_logs_table.php` — `audit_logs`: `user_id` + `organization_id` nullable FKs (nullOnDelete), `entity`, `entity_id` nullable bigint, `action`, `diff` JSON nullable, `at` timestamp useCurrent; composite index `(organization_id, entity, at)`; no Eloquent timestamps
- `app/Models/AuditLog.php` — `$timestamps = false`, `#[Fillable(['user_id','organization_id','entity','entity_id','action','diff'])]`; casts `diff → array`, `at → datetime`; `user()` and `organization()` BelongsTo relations
- `tests/Feature/AuditLogsMigrationTest.php` — 3 tests: columns, no timestamps, composite index via `Schema::getIndexes()`

### Decisions
- **Single `at` timestamp, no `created_at`/`updated_at`:** Audit logs are immutable events. The standard Eloquent timestamp pair is semantically wrong here.
- **`diff` as JSON:** Stores before/after field values as an associative array; cast to `array` for transparent serialization.
- **Nullable `user_id` and `organization_id`:** System-generated events (CLI commands, queued jobs) may not have a user or org context.
- **`Schema::getIndexes()` in tests:** Laravel 13 removed `getDoctrineSchemaManager()`; this is the correct replacement.
