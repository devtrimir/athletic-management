## Plan (Gate 1)

### Scope
Team-event participations now store one `Participation` row per team with `lineup_member_ids` (after P6-T46). Media uploaded on that participation was not surfacing on the linked members' Media tab because the member-media lookup only followed `member_id`. This task fixes the lookup, storage-path resolution, authorization, and roster handling so team photos appear for every lined-up member and adding a new lineup member no longer overwrites the previous one.

### Boost MCP research
- Not required: changes are localized bug-fixes on existing P5M/P6 code; no new packages or patterns.
- Skills consulted: `laravel-best-practices`, `pest-testing`.

### Files to touch
- `app/Services/MediaPathService.php` — tenant-scope-safe organization / path resolution for team and individual participations.
- `app/Http/Controllers/MediaFileController.php` — authorize team participation media via tournament; store under tournament org when `member_id` is null.
- `app/Support/Members/MemberProfileData.php` — include team-event participations where the member is in `lineup_member_ids`.
- `app/Http/Controllers/Api/V1/MemberMediaController.php` — same expanded participation lookup for the API endpoint.
- `app/Http/Controllers/EventParticipantController.php` — upsert one participation per team and merge `lineup_member_ids` instead of replacing.
- `app/Http/Controllers/EventController.php` — exclude members already present in `lineup_member_ids` from participant candidates.
- `app/Http/Requests/EventParticipants/StoreEventParticipantsRequest.php` — relax validation where needed for team flow.
- `database/factories/MediaFileFactory.php` — handle `member_id = null` and generate correct storage paths.
- `tests/Feature/MediaFileTest.php` — regression tests for team-event media upload and member-media API visibility.
- `tests/Feature/EventControllerTest.php` — deferred candidate exclusion test.
- `tests/Feature/EventParticipantControllerTest.php` — team-event upsert tests.

### Schema / endpoints / pages
- No new migrations or endpoints.
- Existing endpoints affected:
  - `POST /participations/{participation}/media`
  - `GET /api/v1/members/{member}/media`
  - `POST /tournaments/{tournament}/events/{event}/participants`
  - `GET /tournaments/{tournament}/events/{event}` (deferred participant-candidates prop)

### Risk + mitigation
- **Risk:** Changing team-event participation write shape could break existing medals/achievements or duplicate rows.
  **Mitigation:** `updateOrCreate` replaced with explicit lookup by `(event_id, team_id, member_id IS NULL)` and merged `lineup_member_ids`; existing tests updated and new tests added.
- **Risk:** Tenant scope hides related member/tournament during path resolution in factories or queued jobs.
  **Mitigation:** `MediaPathService` now resolves organization ids via `withoutGlobalScopes()` fallbacks.

### Test plan
- Pest Feature: team participation media upload succeeds without direct `member_id`.
- Pest Feature: uploaded team media appears in member media API.
- Pest Feature: adding a second team participant merges lineup ids instead of deleting the first.
- Pest Feature: participant candidate list excludes members already in `lineup_member_ids`.

## Summary (Gate 3)

### What changed
- `app/Services/MediaPathService.php` — `buildDirectory()` now resolves the owning organization through tenant scopes safely: member org for individual participations, tournament org for team participations, with `withoutGlobalScopes()` fallbacks so factories and background contexts don't get `null`.
- `app/Http/Controllers/MediaFileController.php` — added `authorizeParticipationMedia()`: individual events are authorized via `MemberPolicy::view`, team events via `TournamentPolicy::update`. Stored `organization_id` falls back from member org to tournament org.
- `app/Support/Members/MemberProfileData.php` — added `memberParticipationIds()` which returns both direct participations and team-event participations where the member appears in `lineup_member_ids`; wired into `mediaPayload()`.
- `app/Http/Controllers/Api/V1/MemberMediaController.php` — same `memberParticipationIds()` expansion; all filters now use the broader participation set.
- `app/Http/Controllers/EventParticipantController.php` — team events now create/update a single `Participation` per `(event, team)` with `member_id = null` and merge new player ids into `lineup_member_ids`; individual events keep the original `(event, member)` upsert.
- `app/Http/Controllers/EventController.php` — `participantCandidates()` excludes members already listed in any team-event participation's `lineup_member_ids`.
- `app/Http/Requests/EventParticipants/StoreEventParticipantsRequest.php` — validation relaxed for team-event rows.
- `database/factories/MediaFileFactory.php` — `forParticipation()` now handles `member_id = null` by resolving the tournament organization and builds deterministic paths via `MediaPathService`.
- `tests/Feature/MediaFileTest.php` — added regression tests for team-event media upload and member-media API visibility.
- `tests/Feature/EventControllerTest.php` — added deferred candidate exclusion test.
- `tests/Feature/EventParticipantControllerTest.php` — added team-event upsert tests.

### Decisions
- **One participation per team for team events:** keeps the roster in a single JSON column rather than one row per player, which matches the `lineup_member_ids` design introduced in P6-T46 and prevents adding a player from clobbering existing ones.
- **Tenant-scope escape in path service:** the comment in `BelongsToOrganization` explicitly allows bypassing the scope in background/factory contexts; media path resolution is one such context because it only needs the raw org id for storage, not user authorization.

### Tests added
- `tests/Feature/MediaFileTest.php`:
  - `team participation media appears on member media API`
  - `media upload for team participation does not require a direct member link`
- `tests/Feature/EventControllerTest.php`:
  - `show deferred participant candidates exclude existing team lineup members`
- `tests/Feature/EventParticipantControllerTest.php`:
  - team-event upsert / merge tests (already present in branch diff)
