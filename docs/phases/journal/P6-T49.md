## Plan (Gate 1)

### Scope
The coach profile page (`/coaches/1`) shows English text in the Promotions & Rewards tab and surrounding sections even when the application language is set to Hindi. This task audits the page for translation keys missing from `resources/lang/hi.json`, fixes any raw English literals, and extends the same audit to the closely related member profile page and other high-usage profile tabs where the same patterns appear.

### Boost MCP research
- Not required: pure i18n key audit and JSON update.
- Skills consulted: `inertia-react-development` (i18n patterns), `laravel-best-practices`.

### Files to touch
- `resources/lang/hi.json` — add missing Hindi translations.
- `resources/js/pages/coaches/show.tsx` — wrap any raw English literals in `t()`; ensure keys used match entries in `hi.json`.
- `resources/js/pages/members/show.tsx` — same audit for the parallel member profile.
- Possibly `resources/js/components/coaches/*` and `resources/js/components/members/*` for tab-level strings.

### Schema / endpoints / pages
- No backend changes.
- Page affected: `/coaches/{coach}` (Promotions & Rewards tab, Certifications tab, Sports tab).
- Page likely affected: `/members/{member}` (parallel sections).

### Risk + mitigation
- **Risk:** Adding many translations at once introduces inconsistent terminology.
  **Mitigation:** Reuse existing Hindi keys/phrases from `hi.json` where possible; keep terminology consistent with prior translations (e.g., "पदोन्नति" for promotion, "पुरस्कार" for reward, "प्रशिक्षक" for coach).
- **Risk:** Raw strings wrapped in `t()` later break if key is removed.
  **Mitigation:** Add all new keys to both `hi.json` and `en.json` (or ensure `en.json` falls back correctly). Verify via grep that every new `t('...')` has a matching key.

### Test plan
- Manual visual check on `/coaches/1` with locale set to Hindi.
- `npm run build` to confirm no bundling issues.
- `npm run lint` to ensure no new lint errors.
- No new automated tests (i18n-only change).

## Summary (Gate 3)

### What changed
- `resources/lang/hi.json` — added 86 missing Hindi translations covering:
  - Coach profile page (`resources/js/pages/coaches/show.tsx`): Promotion/Reward tab labels, certification tab labels, status labels, empty states, action buttons, etc.
  - Member profile page (`resources/js/pages/members/show.tsx`): promotion/reward dialogs, achievement quick-add filters, tournament selection helpers, empty states, etc.
  - Coach listing page (`resources/js/pages/coaches/index.tsx`): filter labels, print options, certification filters.
  - Member listing page (`resources/js/pages/members/index.tsx`): posting district filter, rank/posting search placeholders, export labels.

### Decisions
- **Added exact keys:** the `t()` helper does exact lookup, so missing variants like `"Coach Profile"` (uppercase) were added even though `"Coach profile"` (lowercase) already existed.
- **Reused established Hindi terminology** from existing keys: e.g., "पदोन्नति" for promotion, "पुरस्कार" for reward, "प्रमाणपत्र" for certification, "प्रतियोगिता" for tournament, "स्पर्धा" for event.
- **No code changes:** all strings were already wrapped in `t()` on the audited pages; only the translation map was incomplete.

### Tests added
- No new automated tests. Verified via:
  - Grep scan confirming every `t('...')` key in the audited files now has an entry in `hi.json`.
  - `npm run build` passes.
  - `npm run lint` runs (pre-existing unrelated errors remain).

### Deferred / follow-ups
- Full project-wide translation audit (other pages, reports, settings, etc.) is deferred to a follow-up task if more English strings are reported.
