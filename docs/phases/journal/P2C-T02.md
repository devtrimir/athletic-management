## Plan (Gate 1)

### Scope
Four linked member-module changes requested by the user:
1. `current_unit_id` and `posting_district_id` become mutually exclusive (posted at a unit OR dedicated to a district — never both), enforced server-side and in the form.
2. Remove the `appointment` field; replace with `initial_rank` (rank at hiring). Existing `rank` continues to show the current rank.
3. Apply the same change everywhere: member show/edit/create UI, per-member print preview, member listing print, Excel export, and the sample import template + import parser.
4. Add a member **listing print** (`GET /members/print`) with the official global header (UPPSCB letterhead + watermark, same as `coaches.print`), whose columns match the Excel export exactly.

### Risk + mitigation
- **Risk:** import template column order is a frozen contract — old downloaded sheets break if headings shift. **Mitigation:** `initial_rank` replaces `appointment` at the same position (index 14); import validates headings, so old sheets fail loudly with a heading-mismatch error instead of silently mis-importing. Called out for the user below.
- **Risk:** `initial_rank` is NULL for existing rows (nothing backfills it — see open question). **Mitigation:** optional in forms; print/export show blank.
- **Risk:** extracting the shared print layout could change coach/tournament print output. **Mitigation:** extract verbatim, coach/tournament tests must stay byte-equivalent (note: 5 coach print tests already fail on `main` for unrelated heading-text drift — those stay as-is, not fixed here).
- **Risk:** rows that already have BOTH unit and posting district set (legacy/import data) would become un-editable until one is cleared. **Mitigation:** count such rows during implementation; XOR only blocks new writes; journal notes the data-cleanup step.

### Open questions (user to confirm with approval)

3. **Print filters:** reuse the full member-index filter set (status/sport/category/level/text) like the Excel export, or minimal like coaches (status scope only)? **Default: same filters as the Excel export, so print == Excel for the same query.**
