### Risk + mitigation
- **Risk:** cross-coach document access (nested binding not scoped). **Mitigation:** explicit `abort_unless($specialAchievement->coach_id === $coach->id, 404)` in controller like the member version, plus cross-org test.
- **Risk:** dev DB must not be reset. **Mitigation:** migration verified on scratch DB only (`createdb` + `DB_DATABASE` override + `dropdb`); phpunit uses sqlite :memory:.
