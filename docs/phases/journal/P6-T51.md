## Plan (Gate 1)

### Scope
On `/coaches/{coach}/assignments`, the Role column currently displays raw enum values `HEAD` and `ASSISTANT`. Since the page is specifically for coaches, these should read `Head Coach` and `Assistant Coach` and be translated when the UI language is Hindi.

### Files to touch
- `resources/js/pages/coaches/show.tsx` — map `assignment.role` to readable, translatable labels.
- `resources/lang/hi.json` + `resources/lang/en.json` — add `Head Coach` and `Assistant Coach` keys.

### Schema / endpoints / pages
- No backend changes.
- Page affected: `/coaches/{coach}/assignments`.

### Risk + mitigation
- **Risk:** Other pages also display `HEAD` / `ASSISTANT` and the user might expect a global change.
  **Mitigation:** Limit this task to the coach assignments tab as requested; audit other usages and note them for follow-up if needed.

### Test plan
- Manual visual check on `/coaches/1/assignments` with locale set to Hindi and English.
- `npm run build` and `npm run lint` on the touched file.
