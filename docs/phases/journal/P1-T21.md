### Design
```php
$org = Organization::firstOrCreate(['code' => 'UPP'], [...]);
$rows = [];
foreach (range(2019, 2026) as $year) {
    $rows[] = [
        'organization_id' => $org->id,
        'name' => $year . '-' . substr($year + 1, 2),
        'start_year' => $year,
        'end_year' => $year + 1,
        'is_current' => $year === 2026,
    ];
}
SportSession::upsert($rows, ['organization_id', 'name'], ['start_year', 'end_year', 'is_current', 'updated_at']);
```

### Test plan

- Exactly one `is_current = true` row (2026-27)
