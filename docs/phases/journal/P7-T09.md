## Summary (Gate 3)

### What changed
- `app/Services/Reports/AchievementHistoryReport.php` — DB query joining achievements → participations → members + events → tournaments + tiers + sports; supports session_id / sport_id / tier_id / unit_id filters; orders by date_from DESC, full_name_hi ASC
- `app/Http/Controllers/Api/V1/AchievementHistoryController.php` — thin invokable; uses `ReportFilterRequest::filters()` to pass filters and returns `{data, filters}` JSON
- `routes/api.php` — `GET /api/v1/reports/achievement-history` named `v1.reports.achievement-history`
- `tests/Feature/Reports/AchievementHistoryReportTest.php` — 10 service scenarios (32 assertions total)

- `resources/lang/hi.json` — added `"Achievement History": "उपलब्धि इतिहास"`

### Decisions
- **`allFilters()` vs `filters()`:** `ReportFilterRequest` only exposes `filters()`; `allFilters()` is specific to subclasses like `NewJoinersRequest`. Used `filters()`.
- **Model instances in test helpers:** `BelongsToOrganization` global scope causes `Sport::find($id)` to return null in tests when org context doesn't match. Fixed by accepting model instances (not IDs) in `ahSetup()` helper and using `??=` factory creation.
- **`Organization::withoutGlobalScopes()->find()`:** Used in API test `ahApiSeed()` to retrieve org from user without global-scope interference.

### Tests added

- `tests/Feature/AchievementHistoryApiTest.php` — 4 tests: 401, 403, 200+data, 200+empty
