### Schema / endpoints / pages
No new migrations. No new routes. `GET /api/v1/reports/medals` contract unchanged.

**`MedalTallyReport::run(int $orgId, array $filters): Collection`**

`$filters` shape: `array{session_id: ?int, sport_id: ?int, unit_id: ?int, tier_id: ?int}`

Returns `Collection` of:
```php
['tier' => ['code' => string, 'label_hi' => string, 'weight' => int], 'GOLD' => int, 'SILVER' => int, 'BRONZE' => int, 'MERIT' => int]
```

**unit_id filter:** join `members` on `p.member_id = m.id` and add `WHERE m.current_unit_id = ?` — only when `unit_id` is non-null (avoids unnecessary join).

### Risk + mitigation
- **Risk:** Adding `members` join when `unit_id` is set could slow queries on large data.
  **Mitigation:** `members.current_unit_id` is indexed (FK); join only added conditionally via `->when($unitId, ...)`.
- **Risk:** Refactoring controller could break existing `MedalsPivotApiTest`.
  **Mitigation:** Run the existing test suite immediately after refactor.
