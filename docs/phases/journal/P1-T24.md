### Design
- `AuditLogger::log(action, model, diff?)` writes one `AuditLog` row
- `AuditObserver` handles created/updated/deleted generically via `Model` type hint
- Excluded fields: `created_at`, `updated_at`, `deleted_at`, `password`, `remember_token`, `two_factor_*`
- Observer registered via `#[ObservedBy([AuditObserver::class])]` (not `bootAuditable()` — that causes circular boot)
- `Auditable` trait kept as empty marker for `class_uses_recursive()` checks

### Whitelisted models
District, Sport, SportSession, TournamentTier, Unit, Role

## Boost MCP research
- Checked `audit_logs` migration: `user_id nullable`, `organization_id nullable`, `entity`, `entity_id`, `action`, `diff json`, `at timestamp`
- Laravel 11+: `#[ObservedBy]` attribute preferred over `bootXxx()` trait method (avoids circular boot via `static::observe()` → `new static` during boot sequence)

## Implementation notes
- `bootAuditable()` calling `static::observe()` throws `LogicException` (model boot in progress when `new static` is triggered) — fixed by switching to `#[ObservedBy]` attribute
- `updated` diff only captures actually-changed fields; skips write if all dirty fields are excluded noise

## Summary

**What was built:** `AuditLogger` service + `AuditObserver` writing `created/updated/deleted` diffs to `audit_logs`. Six reference-data models opt in via `Auditable` marker trait + `#[ObservedBy([AuditObserver::class])]`.

**Tests:** 7 tests, 16 assertions — all pass. Pre-existing RbacServiceTest failures (7) confirmed on main before this branch.

**Key decision:** Used `#[ObservedBy]` attribute (Laravel 11+) instead of `bootAuditable()` — calling `static::observe()` inside a trait boot method creates a circular model boot exception.
