- `resources/lang/hi.json` — added member performance tab labels

### Decisions
- **One scoring source:** the member tab does not calculate anything separately; it reads from the same points engine used by the ranking report.
- **Deferred and tab-scoped:** performance data loads as a deferred prop and only mounts when the tab is opened, keeping the main member page leaner.
- **Simple presentation:** the tab uses straightforward tables for summary, leaderboards, session totals, and ledger rows so all contributing data stays visible.
