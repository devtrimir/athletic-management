### Schema / endpoints / pages

**No migration** — `sport_sessions` table exists.

**Endpoints** (all under `auth + verified + permission:reference_data.manage`):

| Method | Path | Name | Action |
|---|---|---|---|
| GET | `/settings/sessions` | `sessions.index` | `index` → Inertia |
| GET | `/settings/sessions/create` | `sessions.create` | `create` → Inertia |
| POST | `/settings/sessions` | `sessions.store` | `store` → redirect index |
| GET | `/settings/sessions/{sportSession}/edit` | `sessions.edit` | `edit` → Inertia |
| PATCH | `/settings/sessions/{sportSession}` | `sessions.update` | `update` → redirect index |
| DELETE | `/settings/sessions/{sportSession}` | `sessions.destroy` | `destroy` → redirect index |

**Policy** (`SportSessionPolicy`):
- `viewAny`, `view`, `create`, `update`, `delete` — all gate on `$user->can('reference_data.manage')`.
- Admin (`is_system=true, code='admin'`) bypasses via `Gate::before` — no special casing needed.

**Validation** (both Requests share the same rules except `name.unique` ignores self on update):
- `name`: required · string · max:10 · `Rule::unique('sport_sessions', 'name')->where('organization_id', $orgId)->ignore($id)`
- `start_year`: required · integer · min:2000 · max:2100
- `end_year`: required · integer · min:2000 · max:2100 · `gt:start_year`
- `is_current`: required · boolean

**is_current logic**: `store` and `update` wrap in `DB::transaction`. If `is_current` is `true`, first set all sessions in the org to `is_current = false`, then save.

**Org scoping**: `BelongsToOrganization` global scope not yet in place (P1-T16). Controller scopes manually: `SportSession::where('organization_id', $request->user()->organization_id)`.

**Pages**:
- `settings/sessions/index` — Tailwind `<table>` (no shadcn table yet), Edit/Delete per row, "+ New session" link
- `settings/sessions/create` — form: name, start_year, end_year, is_current checkbox; uses `<Form {...store.form()}>` (Wayfinder)
- `settings/sessions/edit` — same form pre-filled; uses `<Form {...update.form(session.id)}>` (Wayfinder patch)

All pages use `Heading`, `Label`, `Input`, `Button`, `InputError` + `Page.layout = { breadcrumbs: [...] }` convention from `profile.tsx`.

### Risk + mitigation

- **Risk:** ~500+ LOC / 9 files — above 400 LOC threshold from phase file.
  **Mitigation:** All 9 files are a single tightly-coupled CRUD slice with no branching logic. Split would hurt coherence more than it would help. Proceeding as one task; noting in journal.
- **Risk:** `is_current` race condition (two concurrent requests could both set `is_current = true`).
  **Mitigation:** DB transaction + single UPDATE scoped to org.
- **Risk:** Wayfinder not yet generated for new controller.
  **Mitigation:** Run `php artisan wayfinder:generate --with-form --no-interaction` immediately after adding the controller.

### Test plan

Pest Feature (`tests/Feature/Settings/SportSessionCrudTest.php`), `test()` style, `RefreshDatabase` via global config:

- `beforeEach`: seed `OrganizationSeeder` + `AdminUserSeeder` → get `admin@upp.local` as actor.
- index lists sessions for the authenticated user's org (200, Inertia response)
- create page is accessible (200, Inertia)
- store creates a session and redirects to index
- store with `is_current=true` flips all others to `false`
- edit page is accessible for own-org session (200, Inertia)
- update modifies the session and redirects
- destroy removes the session and redirects
- 403 for unauthenticated user on every verb
- 403 for a user without `reference_data.manage` permission
- cannot edit/delete a session belonging to another org (404 or 403 via policy)
