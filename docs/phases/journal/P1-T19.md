## Plan (Gate 1)

### Scope
Create `database/data/up_districts.csv` with all 75 official UP districts (Hindi + English + code), a `DistrictSeeder` that reads it and upserts idempotently, and register it in `DatabaseSeeder`. Test verifies the seeder inserts exactly 75 rows and is idempotent.

### Boost MCP research (mandatory)
- `search-docs` packages=[laravel/framework] queries=["seeder upsert idempotent csv"] → confirmed `Model::upsert($rows, ['code'])` is the right approach; safe to re-run.
- `database-schema` for `districts` table → `id, name_hi, name_en, state, code (unique), timestamps`.

### Files to touch
| File | Change |
|---|---|
| `database/data/up_districts.csv` | new — 75 rows, header: `name_hi,name_en,code` |
| `database/seeders/DistrictSeeder.php` | new — reads CSV, upserts on `code` |
| `database/seeders/DatabaseSeeder.php` | call `DistrictSeeder` |
| `tests/Feature/DistrictSeederTest.php` | new |

### Design
- CSV columns: `name_hi,name_en,code` (state = "Uttar Pradesh" hardcoded in seeder — all districts are UP)
- `District::upsert($rows, uniqueBy: ['code'], update: ['name_hi', 'name_en', 'state', 'updated_at'])` — safe to run multiple times
- Seeder reads CSV with `SplFileObject` (no external deps)

### Test plan
- Run `DistrictSeeder` → `District::count()` equals 75.
- Run `DistrictSeeder` a second time → still 75 (idempotent).
- Spot-check: Lucknow (लखनऊ / LKO) and Varanasi (वाराणसी / VNS) are present.
