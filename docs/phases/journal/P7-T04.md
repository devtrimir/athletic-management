## Summary (Gate 3)

### What changed
- `app/Services/Reports/TeamRosterReport.php` — new; single LEFT JOIN query (`teams → sports → sport_sessions → units → team_members → members`), PHP-grouped by `team_id`; teams with no members return an empty `members` array; CAPTAIN sorts before PLAYER/RESERVE via `CASE` expression
- `app/Http/Controllers/Api/V1/TeamRosterController.php` — new invokable; injects service; uses `ReportFilterRequest` (no extra params needed)
- `routes/api.php` — `GET /api/v1/reports/team-roster` → `v1.reports.team-roster`
- `tests/Feature/Reports/TeamRosterReportTest.php` — 8 service tests
- `tests/Feature/TeamRosterApiTest.php` — 4 API tests

### Decisions
- **LEFT JOIN on team_members:** ensures teams with zero members appear in the report (right behaviour — staff need to see empty squads). Members with `deleted_at` excluded via join condition.
- **No new request class:** `ReportFilterRequest` suffices; `tier_id` is silently ignored since teams don't link to tournament tiers.

12 passed (27 assertions). No regressions.
