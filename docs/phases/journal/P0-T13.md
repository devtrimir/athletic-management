- `docs/adr/README.md` — 0001 and 0002 marked Accepted.

### Decisions
- **No import pipeline:** User confirmed legacy Excel data will not be imported; data entered
  manually. ADR-0002 context updated accordingly.
- **maatwebsite/excel over fast-excel:** Merged cells and Devanagari font embedding required for
  P7 styled XLSX reports. fast-excel lacks these features.
