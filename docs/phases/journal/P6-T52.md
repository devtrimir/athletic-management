# P6-T52 — Cross-module guards: block deleting tournament/event/participation/medal when used as coach or member promotion/reward evidence

## Plan (Gate 1)

### Scope
Coach and member promotions/rewards are backed by evidence drawn from tournaments, events, participations, and achievements. Currently, deleting or editing those source records does not check whether promotions/rewards depend on them, which can silently orphan evidence. This task adds backend guards that block destructive actions when dependent promotion/reward evidence exists, and surfaces the conflict to the user.

### Files to touch
- `app/Services/PromotionDependencyGuard.php` — new service to detect dependencies.
- `app/Http/Controllers/TournamentController.php` — guard `destroy`.
- `app/Http/Controllers/EventController.php` — guard `destroy`.
- `app/Http/Controllers/EventParticipantController.php` — guard `destroy` and medal-changing `update`.
- `resources/lang/hi.json` + `resources/lang/en.json` — conflict messages.
- `tests/Feature/PromotionDependencyGuardTest.php` — unit/feature coverage.

### Schema / endpoints / pages
- No migrations.
- Endpoints affected:
  - `DELETE /tournaments/{tournament}`
  - `DELETE /tournaments/{tournament}/events/{event}`
  - `DELETE /tournaments/{tournament}/events/{event}/participations/{participation}`
  - `PATCH /tournaments/{tournament}/events/{event}/participations/{participation}` (when medal changes)

### Risk + mitigation
- **Risk:** Over-blocking legitimate edits.
  **Mitigation:** Only block when the specific achievement/participation/tournament/event is directly referenced as evidence; allow edits that do not touch the medal or remove the record.
- **Risk:** Coach evidence stores `event_id`/`achievement_id` as nullable, making some links inferential.
  **Mitigation:** Check the concrete stored IDs first; for coach reward evidence linked only by tournament+team+session, also check whether any achievement in that scope is being removed.

### Test plan
- Pest Feature: deleting a tournament with coach reward evidence returns 422/redirect with error.
- Pest Feature: deleting a participation that is member-promotion evidence returns error.
- Pest Feature: updating/removing a medal that is evidence returns error.
- Pest Feature: non-destructive edits remain allowed.
