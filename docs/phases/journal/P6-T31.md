## Plan (Gate 1)

### Scope
The certifications tab on the coach profile lets users add certifications but cannot attach a document. Add file upload (pdf/jpeg/png/webp, max 5 MB — existing app convention) to certification create/edit, store privately on the `local` disk, and show a "View document" button per row that opens the existing `ConfidentialDocumentPreview` modal with inline preview + download. Mirrors the member special-achievements `order_document` pattern.

### Risk + mitigation
- **Risk:** existing `attachment_path` rows contain free-text paths (field was a text input) — downloading would 404 or leak.
  **Mitigation:** controller 404s on missing file; only stored-file paths are rendered as viewable attachments.
- **Risk:** multipart on edit — the upsert uses POST already; Inertia `useForm.post` sends multipart automatically when a File is present. Verified no method-spoof needed.
- **Risk:** org scoping — file path must include organization scope like the member pattern.

## Implementation notes (2026-09-04, Gate 2 complete)

### What changed
- Migration `2026_09_04_165018_add_attachment_meta_to_coach_certifications_table` adds `attachment_original_name`, `mime_type`, `size_bytes` (all nullable) to `coach_certifications`.
- `CoachCertification` model fillable + PHPDoc + factory updated for the new columns.
- `StoreCoachCertificationRequest`: `attachment_path` string rule replaced with `attachment => nullable|file|mimes:pdf,jpeg,jpg,png,webp|max:5120`.
- `CoachCertificationController`: `store()` stores uploads on the `local` disk under `coach-certifications/{organization_id}` and persists the meta columns; upsert-by-id deletes the previously stored file when a replacement is uploaded. `destroy()` hard-deletes the stored file (row is soft-deleted; preview must stop working) with the same prefix guard. New `previewAttachment()` (`response()->file()` inline, stored mime) and `downloadAttachment()` (`Storage::disk('local')->download()` with original name). Legacy free-text `attachment_path` values are never treated as files: delete skips them, preview/download 404 via a `coach-certifications/` prefix guard + `Storage::exists` check.
- Read authorization: `Gate::authorize('view', $coach)` (matches member order-document pattern); writes keep `updateCertifications`. Cross-coach access 404s via manual `coach_id` check (mirrors member controller; route is not scope-bound).
- Routes: `GET coaches/{coach}/certifications/{certification}/attachment` → `coaches.certifications.attachment.download`; `GET coaches/{coach}/certifications/{certification}/attachment/preview` → `coaches.certifications.attachment.preview`. Wayfinder actions regenerated (`php artisan wayfinder:generate`; gitignored).
- Payload: built in `CoachResource` (the certifications tab renders `coach.certifications` from this resource, not `CoachProfileData`): per-row `attachment: {preview_url, download_url, original_name, mime_type, size_bytes} | null`; `attachment_path` dropped from the resource, `null` when path is empty or not under `coach-certifications/`. `CoachProfileData` column selections extended with the new meta columns. `coach-quick-view.tsx` type updated to match.
- Frontend `coaches/show.tsx`: `CoachCertification.attachment` type matches `ConfidentialDocument`; "Attachment path" text input replaced with the member-pattern file input (accept pdf/jpeg/png/webp, hint text, `key` remount on dialog open to reset the DOM input); edit mode shows "Current file: :name — choose a file to replace"; table cell renders `<ConfidentialDocumentPreview triggerLabel={t('View document')} />` when an attachment exists, em-dash otherwise. Edit path still POSTs (multipart auto via Inertia).
- `hi.json`: added `Attachment`, `Upload attachment`, `View document`, `Current file: :name — choose a file to replace`, `PDF, JPG, PNG, or WEBP. Stored privately and available only to authorized users.`
