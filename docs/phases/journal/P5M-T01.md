### Schema
Migration `media_files`:
- org-scoped polymorphic (`mediable_type`, `mediable_id`)
- `disk` varchar default 'public'
- `path` varchar unique (deterministic storage path)
- `original_name`, `mime_type`, `size_bytes`
- `caption_hi` nullable
- `uploaded_by` FK → users
- indexes: mediable composite, org+uploaded_by, org+created_at

### Risk + mitigation
- **Risk:** `path` unique constraint — if two files uploaded for same context get same generated name
  **Mitigation:** `MediaPathService` (PR 2) uses `{uuid}.{ext}` as filename within the deterministic dir
