### Risk + mitigation
- **Risk:** `down()` must drop foreign keys before dropping the table.
  **Mitigation:** Use named FKs in `up()` so `down()` can drop them by name.
- **Risk:** `(organization_id, pno)` unique index with NULLable `pno` — MySQL 8 treats each NULL as distinct so duplicates aren't blocked for NULL rows.
  **Mitigation:** Enforce `pno` uniqueness in the Form Request (`Rule::unique(...)->whereNotNull('pno')`) — documented in P2-T09.
