### Decisions
- **Variable fonts (5 files) instead of per-weight files (8 files):** Google Fonts serves Noto Sans Devanagari as a variable font where the same woff2 covers all weights via the weight axis. Inter from Google Fonts behaves identically. Using `font-weight: 100 900` in `@font-face` correctly declares this; browsers request the single file and use the weight axis. Fewer files, same rendering.
- **Latin + Latin-Ext subsets only for Inter:** Devanagari rendering is handled entirely by Noto Sans Devanagari. Inter only needs Latin/Latin-Ext for the English UI chrome (numbers, labels, etc.).
- **3 subsets for Noto Sans Devanagari:** Devanagari (primary) + Latin + Latin-Ext for mixed-script strings (e.g. "UP Police 2026-27").
- **Removed `bunny()` from `vite.config.ts`:** The starter kit loaded `Instrument Sans` from Bunny CDN. Removing this eliminates the external font call entirely and drops `fonts-manifest.json` from the build.
