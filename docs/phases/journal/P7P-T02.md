## Summary (Gate 3)

### What changed
- `app/Services/Performance/PlayerPointsService.php` — added the scoring engine that produces audited participation rows plus grouped summaries by member, session, sport, and tier
- `tests/Feature/PlayerPointsServiceTest.php` — added coverage for empty output shape, score math, award overrides, filters, org isolation, and member ordering
- `docs/phases/journal/P7P-T02.md` — recorded task plan and outcome

### Decisions
- **One engine, multiple views:** the service returns both detailed rows and grouped summaries so the future report and member profile can share the exact same score calculation.
- **Tier bonus applies only to achievement rows:** plain participation gets base points, while medal-based performance also earns the configured tier bonus.
- **Award override wins:** `points_override` on a participation award replaces the configured award score for that record.
