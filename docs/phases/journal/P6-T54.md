# P6-T54 — Remove designation field from incharge module and team incharge surfaces

- **Task ID:** P6-T54

## Plan (Gate 1)

### Scope
Remove the `designation` field from all user-facing surfaces and data flows for the team prabhari (incharge) module: forms, listing search, profile/show, print preview, and the team incharge panel. The underlying database columns are kept, so no migration or data loss is involved.

### Files to touch

#### Backend
- `app/Models/Incharge.php` — remove `designation` and `designation_en` from `$fillable`.
- `app/Models/TeamInchargeAssignment.php` — remove `designation` from `$fillable`.
- `app/Http/Requests/Incharges/StoreInchargeRequest.php` — remove `designation` rule.
- `app/Http/Requests/Incharges/UpdateInchargeRequest.php` — remove `designation` rule.
- `app/Http/Controllers/InchargeController.php` — remove designation from search filter, edit payload, and `formOptions()`.
- `app/Support/Incharges/InchargeProfileData.php` — remove `designation` from shell and assignment payloads.
- `app/Support/Teams/TeamProfileData.php` — remove `current_incharge_designation` and `designation` from incharge-related data.
- `app/Actions/Teams/AssignTeamInchargeAction.php` — stop copying `incharge->designation`.
- `app/Actions/Teams/ChangeTeamInchargeAction.php` — stop copying `incharge->designation`.
- `database/factories/InchargeFactory.php` — remove `designation`.
- `database/factories/TeamInchargeAssignmentFactory.php` — remove `designation`.

#### Frontend
- `resources/js/pages/incharges/form.tsx` — remove designation field, state, and `designations` prop.
- `resources/js/pages/incharges/create.tsx` — stop passing `designations`.
- `resources/js/pages/incharges/edit.tsx` — stop passing `designations`.
- `resources/js/pages/incharges/index.tsx` — update search placeholder.
- `resources/js/pages/incharges/show.tsx` — remove Designation row from overview.
- `resources/js/pages/incharges/print.tsx` — remove designation from type/default and overview row.
- `resources/js/components/teams/team-incharge-panel.tsx` — remove designation from current/history display and search placeholders.

### Test plan
- `npx eslint` on changed JS/TS files.
- `npm run build`.
- `vendor/bin/pint --dirty --format agent`.
- `php artisan test --compact` (or targeted Pest run if the pre-existing full-suite fatal remains).
