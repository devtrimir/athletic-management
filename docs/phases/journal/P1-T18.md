### Props shape after change

```php
'auth' => [
    'user'        => $request->user(),
    'permissions' => fn () => [...],  // string[] of permission codes, [] for guests
],
'locale' => fn () => app()->getLocale(),   // SetLocale ran first — correct value guaranteed
```

`permissions` wrapped in a lazy closure so it doesn't hit Redis on every request that doesn't render an Inertia page (e.g. redirects, API).

### Test plan
- Authenticated user with permissions → Inertia response shares correct `auth.permissions` array.
- Guest request → `auth.permissions` is `[]`.
- `locale` prop reflects the value set by `SetLocale`.
