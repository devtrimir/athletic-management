### Props shape after change

```php
'auth' => [
    'user'        => $request->user(),
    'permissions' => fn () => [...],  // string[] of permission codes, [] for guests
],
'locale' => fn () => app()->getLocale(),   // SetLocale ran first — correct value guaranteed
```

`permissions` wrapped in a lazy closure so it doesn't hit Redis on every request that doesn't render an Inertia page (e.g. redirects, API).

### Test plan
- Authenticated user with permissions → Inertia response shares correct `auth.permissions` array.
- Guest request → `auth.permissions` is `[]`.
- `locale` prop reflects the value set by `SetLocale`.

## Summary (Gate 3)

### What changed
- `app/Http/Middleware/HandleInertiaRequests.php` — added `'translations' => fn () => $this->loadTranslations()` and `'flash' => fn () => ['toast' => $request->session()->get('flash.toast')]` to `share()`. Added private `loadTranslations()` that reads `lang_path("{locale}.json")` and returns decoded array (or `[]` if file absent).
- `resources/lang/hi.json` — created with `{}`
- `resources/lang/en.json` — created with `{}`
- `resources/js/types/global.d.ts` — imported `FlashToast` from `@/types/ui`; added `translations: Record<string, string>` and `flash: { toast?: FlashToast }` to `sharedPageProps`.
- `tests/Feature/InertiaSharedPropsTest.php` — 4 Pest tests (all passing).
- `docs/TASKS.md` — ticked ~24 completed Phase 1 tasks; added Phase FT.

### Decisions
- **Lazy closures:** both new props are wrapped in `fn()` consistent with `auth.permissions` and `locale`.
- **Empty placeholder files:** `hi.json` and `en.json` ship as `{}`. P9-T01 will populate actual strings.
- **`[]` fallback:** `loadTranslations()` returns `[]` if JSON file missing — no errors on fresh installs.
