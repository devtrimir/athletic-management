- `tests/Feature/UsersExtensionMigrationTest.php` — columns present, default locale, nullOnDelete FK

### Decisions
- **`nullOnDelete` not `cascadeOnDelete`:** Users should survive an org deletion (soft-deactivation scenario) rather than be hard-deleted.
- **`locale` on users (not just session):** Authenticated users carry a persistent locale preference; `SetLocale` middleware (P0-T12) already reads session, and P1-T17 will extend it to prefer `users.locale`.

### Tests added
- `tests/Feature/UsersExtensionMigrationTest.php` — columns, FK behavior, defaults

### Deferred / follow-ups
