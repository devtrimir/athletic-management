## Summary (Gate 3) — fill after implementation

### What changed
- `name_en` added to all `Rank::active()->ordered()->get(...)` selects: `MemberController` (index/create/edit/memberViewProps ×4) and `MemberProfileData::referenceData`.
- `MemberProfileData::print()` now ships a `ranks` prop (code, name, name_en, short_name) for print-preview.
- `MemberPreviewController` (quick-view API) now ships `ranks`.
- `MemberExportController`: new private resolvers `resolveRankLabel` (case-insensitive name_en/short_name lookup, locale-aware, raw fallback), `resolvePlayerCategoryLabel` (`SKILLED`→`SPORTS_QUOTA` then `__()`), `resolvePlayerLevelLabel` (TournamentTier label_en/label_hi by locale); applied in `memberRow()` so both `print()` and Excel `index()`/`show()` benefit (show() refactored to reuse memberRow).
- New shared frontend resolver `resources/js/lib/ranks.ts` (`resolveRankLabel` + `RankOption` type); used in `members/index.tsx` (rank chip + rank filter pill/option list), `members/show.tsx` (Rank + Initial rank rows), `member-quick-view.tsx` (header chip, InfoRow, print HTML), `members/print-preview.tsx` (Rank + Initial rank rows).
- `resources/lang/en.json`: added `GD` → "General Duty", `SPORTS_QUOTA` → "Sports Quota" (en previously fell back to raw keys; hi.json already had both).
- New `tests/Feature/MemberExportControllerTest.php` (7 tests: hi/en print rows, raw fallback, SKILLED mapping, Excel export paths, index `name_en` payload, preview `ranks` payload).

### Decisions
- Quick-view gets `ranks` from the preview API (no extra endpoint); the frontend resolver runs against page locale.
- `en.json` keys added (not hi.json) so `__('SPORTS_QUOTA')` resolves in English exports/UI; no other new lang keys were needed.
- Export headings (`COLUMN_LABELS`) left English-only per scope.
