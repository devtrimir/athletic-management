## Plan (Gate 1)

### Scope
Provide a safe, sophisticated member deletion experience with pre-deletion connection/impact analysis and clean disengagement.
Before soft-deleting a member, inspect and display all references across the system (active team rosters, linked coach profile, tournament participations/medals, external coaching assignments, special achievements, promotions).
Upon confirmation, soft-delete the member, gracefully decouple active associations (mark active team rosters as departed today, unlink coach profile, conclude active external assignments) in an atomic database transaction, and preserve historical records without orphaned references.

### Schema / endpoints / pages
- **New Endpoint:** `GET /members/{member}/deletion-impact` (`members.deletion-impact`) — returns JSON breakdown of active and historical connections
- **Updated Endpoint:** `DELETE /members/{member}` (`members.destroy`) — executes atomic disengagement and soft-deletes member
- **New Component:** `resources/js/components/members/delete-member-dialog.tsx`

### Risk + mitigation
- **Risk:** Soft-deleting a member without ending active team rosters leaves dangling players or null references when teams query roster members.
  **Mitigation:** `MemberDeletionService` sets `team_members.left_on = now()` for all active memberships, ensuring team rosters and player counts accurately reflect departure.
- **Risk:** Linked Coach record (`coaches.member_id`) breaks if member is deleted.
  **Mitigation:** `MemberDeletionService` safely sets `coaches.member_id = null` inside the transaction.
- **Risk:** Accidental deletion of high-profile athletes with historical records.
  **Mitigation:** Destructive dialog requires typing the member's PNO (or member code) when active connections exist before enabling the delete button.

### Test plan
- **Pest Feature (`tests/Feature/MemberDeletionTest.php`):**
  - Unauthorized user (without `members.delete` permission) gets 403 on impact endpoint and destroy endpoint.
  - Member deletion impact endpoint returns accurate counts of active teams, past teams, participations, medals, linked coach, and external coaching.
  - Deleting member with active team roster marks `team_members.left_on = now()` and reduces team active player count.
  - Deleting member linked to a coach clears `coaches.member_id` while preserving the coach.
  - Deleting member with participations/achievements retains historical records in the database (`withTrashed()`).
  - Deleting member sets `members.deleted_at = now()` and creates an `AuditLog` entry.

### Decisions
- **Soft Deletion with Active Disengagement:** Rather than a raw soft delete that leaves dangling references, active squad rosters are marked departed (`left_on = today`) and coach links are set to `null`. This preserves historical logs while ensuring active squad counts and queries do not see deleted members.
- **Safety Confirmation Guard:** For members with active connections, the dialog requires typing the member's PNO or Member Code to prevent accidental administrative clicks.
