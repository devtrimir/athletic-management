
## Summary (Gate 3)

**Status:** done — all files implemented, lint clean, build green, 24 tests passing.

### What was built
- `TeamController::formOptions()` private helper — shared by `create()`, `edit()`. `show()` now also loads relations and passes deferred `members` + `coaches`.
- `resources/js/components/coach-picker.tsx` — mirrors MemberPicker, uses `CoachSearchController`, `CoachOption` type includes `id, full_name_hi, full_name_en, pno, nis_certified`.
- `resources/js/pages/teams/create.tsx` — `setLayoutProps` breadcrumbs, `useForm` with sport/session/unit Selects + name_hi/in_charge_hi Inputs.
- `resources/js/pages/teams/edit.tsx` — same form pre-populated from `team` prop, submit via `patch(update.url(team))`.
- `resources/js/pages/teams/show.tsx` — Overview/Players/Coaches tabs; deferred `members` + `coaches`; inline `AddMemberPanel` + `AddCoachPanel` sub-components; delete with `confirm()`.
- `resources/lang/hi.json` — 18 new keys including role enums PLAYER/CAPTAIN/RESERVE/HEAD/ASSISTANT.

### Key decisions
- `formOptions()` re-runs the same three queries for create/edit — avoids passing org-scoped data via shared props.
- Show page derives the sessions list from `team.session` for the add-member/coach panels (single session per team). This is intentional — teams are scoped to one session.
- Members are removed by `member.id` (not pivot ID) matching `TeamMemberController::destroy(Team, Member)`.
