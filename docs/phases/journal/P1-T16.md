## Plan (Gate 1)

### Scope
Create the multi-tenancy infrastructure: a `BelongsToOrganization` Eloquent global scope and a `Tenanted` model trait that auto-applies it. No domain models are modified in this task — the trait is created ready to be adopted when models are added in P2+.

### Boost MCP research (mandatory)

### Files to touch

### Implementation detail

**`BelongsToOrganization` scope:**
```php
public function apply(Builder $builder, Model $model): void
{
    $builder->where($model->getTable() . '.organization_id', auth()->user()?->organization_id ?? 0);
}
```
- Unauthenticated requests receive `organization_id = 0` (impossible value) → zero rows returned — prevents data leaks.

**`Tenanted` trait:**
```php
protected static function booted(): void
{
    static::addGlobalScope(new BelongsToOrganization);
}
```
PHPDoc documents the escape hatch: `withoutGlobalScope(BelongsToOrganization::class)` is allowed **only** in background reindex jobs (queued, not user-facing).

### Risk + mitigation
- **Risk:** Existing tests that create `Role` (or other org-scoped models) may fail if `Tenanted` is inadvertently added to those models.
  **Mitigation:** No models are changed in this PR. `Tenanted` is created but not yet applied.
- **Risk:** The scope fires during unauthenticated routes (e.g., login page).
  **Mitigation:** `?? 0` guard returns an empty result set rather than throwing — safe.
